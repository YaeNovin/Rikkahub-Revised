# 材质与背景解耦、输入区与浮层亚克力

日期：2026-09-28。工作区实现，非发布说明。

## 控制关系

背景负责图片／渐变来源；材质负责区域的表面外观；效果开关与设备能力只决定实际绘制是否使用模糊和光学层。关闭或移除背景，不修改已选材质、透明度及模糊半径。

- 输入区与其他表面共用 `BackgroundSurfaceStyle` 类型，包含实色、半透明、磨砂、液态玻璃和新增亚克力。亚克力当前仅在输入区和浮层设置中提供。
- `composerSurfaceStyle` 是可空新增配置。缺失时沿用旧 `enableBlurEffect`／`liquidGlass.applyToComposer` 推导，用户选择新材质后原子保存显式材质并同步旧标志。旧 Dock 迁移不会覆盖显式材质。
- 页面材质入口从“有图片才显示”调整为始终可用。卡片透明度由材质决定：实色固定不透明，其余材质使用配置值，即使没有图片也可使用。
- 侧栏材质与参数不再以聊天壁纸作为编辑前提；暂停侧栏效果只停止光学层，保留材质底色。没有图片时使用主题底色，不伪称有真实内容可模糊。
- 浮层材质可随时选择，透明度与模糊参数不再依赖背景图片。新增独立的“浮层材质效果”开关。
- 顶栏参数可预先编辑；现有顶栏仍使用壁纸采样，未扩展成聊天内容实时采样。聊天气泡与渲染富内容保持原有独立样式，本轮未新增亚克力。
- 选择／替换全局背景图片不再把实色材质自动切换成半透明；若当前为实色，会明确提示图片已保存，但需要选择其他页面材质才显示。
- 云母仍为上一阶段的局部预览，没有强制替换全局主题，也没有恢复正文／代码块自动补底。

## 亚克力绘制

| 区域 | 内容来源 | 绘制方式 |
| --- | --- | --- |
| 输入框、附件与 Dock 共用表面 | 原有聊天 Haze 源 | 实时背景模糊，前景文本独立绘制 |
| 弹窗、菜单、底部面板 | 当前 Activity 窗口快照 | 打开时采样，尺寸变化重取，不连续采集后方动画 |
| 不支持模糊、关闭效果、省电或采样失败 | 当前主题 | 保留材质配置并退回主题染色表面 |

表面只叠加一层低强度主题染色、缓存的静态细颗粒和轻量边界，不叠加液态玻璃折射。复用区域原有透明度和模糊半径，不为新材质重置旧值。透明度为零时不绘制染色、颗粒或边界；实色模式使用不透明底色，并保留其他材质的参数以便恢复。

输入区暂停效果后仍保留配置的透明度。跨窗口浮层无法可靠地在所有设备上实时采样，因此暂停效果／省电时停止快照与颗粒，使用不透明的主题基底承载配置的染色层；这是运行时回退，不改写保存的透明度。

### 快照边界

- PixelCopy 仅读取应用 Activity 的窗口，不是屏幕截取，不包含其他应用或系统 UI。
- 浮层必须是独立窗口；同窗口组件不采样自身，避免把前景重复画入背景。
- 最长边最多 1280 px，按比例缩小；不存盘、不上传。方向／布局尺寸变化时丢弃旧坐标，关闭浮层后不保留全局缓存。
- 尊重 `FLAG_SECURE`，不支持或失败时回退主题底层；只做有限重试，不启用持续轮询。
- 背景与浮层通过屏幕坐标对齐，菜单内容滚动不移动背景；前景文本不加入模糊输入。
- 输入区沿用硬件模糊支持判断，在交互繁忙时限制强度；省电时停用亚克力模糊和颗粒。没有新增依赖或渲染引擎。

## 验证记录

本轮增加了材质 JSON 往返、旧配置兼容、背景添加／替换／移除、效果与能力降级、透明度边界、快照尺寸限制等回归。最终 87 项定向 JVM 测试通过，无失败、错误或跳过；Debug 包构建及 QA Kotlin 编译通过，`git diff --check` 通过。首次两项仍要求侧栏依赖壁纸的旧断言已按新规则更新，其余既有验证继续保留。

按 Android QA 流程，在 vivo V2301A / API 36 上使用独立包 `me.rerere.rikkahub.revised.renderperf`，通过 Debug 专用 `AcrylicPreviewActivity` 验证固定条纹和圆形背景。该窗口不读取聊天，也不改写任何外观设置，不进入 QA／Release。

- 已实际查看输入区模糊、弹窗、菜单、深色底部面板和关闭效果后的截图。
- 输入区相同透明度下，将模糊半径从 0 调至 20，避开前景文字的条纹亮度振幅从 44.45 降至 6.07（约为原来的 13.7%），确认是实际模糊，不是仅改变底色。
- 弹窗和菜单可见与后方圆形位置对应的模糊轮廓；前景文字保持清晰。关闭效果时快照消失，浮层呈主题回退色，输入区仍透出未模糊条纹。
- 截图和 UI 树位于构建目录 `app/build/outputs/acrylic-preview/`，不随源码发布。像素检查脚本位于临时构建目录 `build/verify-acrylic-pixels.ps1`。
- 这不是跨设备性能或无障碍认证。尚未覆盖全部 Android 版本、折叠屏／多窗口切换、叠加多层对话框、所有用户壁纸和持续帧时间／功耗。

本轮没有构建或覆盖安装常规 QA 测试包；仅使用独立 Debug 包验证。完成后已卸载临时独立包并删除设备上的两份固定样例截图／UI 树临时文件，本地验证产物和安装包仍保留。设备原有 QA 版本仍为 `2.4.8-revised.9-20260928-142445`。
