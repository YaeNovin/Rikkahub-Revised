# Web 与 Android 功能同步检查及设置页建议

检查日期：2026-10-06。依据当前源码静态核对；本轮只新增检查文档，未实现下列规划，也未重复运行设备测试。

后续落地：用户已确定六类板块，助手设置独立放在聊天页“更多”弹窗。设置页第一阶段已实现，范围与验证见 [实施记录](webui-settings-page-2026-10-06.md)。下文保留检查时的原始建议，不代表所有功能都已实现。

## 判断

建议新增独立 `/settings` 页面。Web 当前只有 `/` 和 `/c/:id`，承担了聊天和少量快捷选择；继续将所有管理功能塞入输入栏/侧栏菜单会使权限、保存范围及状态难以表达。

设置页应共用手机端业务配置与校验逻辑，同时保留浏览器自己的展示偏好。手机数据库/SettingsStore 是共享配置的唯一来源；不复制一套浏览器侧模型、助手或知识库数据库。

## 当前具备的能力

- 聊天发送、停止、重新生成、消息编辑与分支选择、工具批准/交互问题。
- 会话搜索、重命名、置顶、移动、文件夹；附件上传与访问；Markdown 导出。
- 助手/模型切换、模型收藏、推理等级、搜索开关与服务选择、模型内置工具开关。
- 选择已有 MCP 服务、模式注入、世界书、快捷消息绑定。
- 部分显示设置从手机经 settings SSE 推送并生效：用户头像/昵称、模型图标/名称、token 用量、思考展示、代码换行/行号、发送快捷键、长文本转附件。
- 浏览器自身已有主题、暗色/亮色、自定义 CSS 和语言选择，存于 localStorage。

上述快捷设置已有部分写回 API，但没有完整的提供商/助手/服务管理页。工具结果能显示、模型能调用某功能，不等于浏览器拥有该功能的管理界面。

## 已查实的同步缺口

| 项目 | 当前状态 | 应落地的行为 |
| --- | --- | --- |
| 字号 `fontSizeRatio` | DTO 和 TS 已声明，Web 渲染未读取 | 接入实际聊天字体，并允许跟随手机或浏览器覆盖 |
| 自动滚动 `enableAutoScroll` | 已下发但组件固定 StickToBottom 行为 | 尊重开关，用户上滚时不抢位置，重新到底部后恢复 |
| 代码自动折叠 `codeBlockAutoCollapse` | 已下发但未消费 | 首次呈现遵守默认，用户手动展开状态不被流更新重置 |
| LaTeX 开关 | Android 有 `enableLatexRendering`，Web 白名单没有 | 补安全字段投影、UI 与渲染分支 |
| 主题 | Android `dynamicColor/themeId` 已下发，Web ThemeProvider 使用本地主题 | 明确主题语义；不能把 Android 主题 ID 直接当作 Web CSS 主题 |
| 建议回复 | Web 只消费建议文本，点击固定替换草稿 | 同步插入模式/显示选项；保留追加等本体行为；随后接入暂停、刷新、反馈等控制 |
| 会话系统提示词 | DTO 有 `customSystemPrompt`，助手有允许标志；无对应编辑操作 | 会话详情内增加编辑/恢复助手默认，后端验证助手许可 |
| 工作区模式 | `workspaceCwd/workspaceFileOperationMode` 已同步类型，没有设置入口 | 先显示当前工作区与模式，再增加白名单修改 API；授权根目录仍由 Android 处理 |
| 翻译 | MessageDto 有 translation，Web 无消费/发起入口 | 展示已生成译文，复用手机翻译服务发起翻译 |
| 活跃助手 | Web 从共享 `settings.assistantId` 读取，切换会写全局 | 明确共享语义，评估多浏览器是否需要独立导航选择；修改前不得默默改变现有行为 |

第一批应先修复“字段下发但未生效”，否则新增设置开关会造成虚假同步。

## 应与本体共享的业务设置

| 顺序 | 模块 | 建议同步内容 | 当前需要补齐 |
| --- | --- | --- | --- |
| 1 | 助手基础与生成 | 名称/头像、系统提示词、temperature/topP/maxTokens、流式输出、上下文压缩、默认模型与推理等级 | 安全详情 DTO、编辑接口、保存校验；当前主要只有选择类 API |
| 1 | 默认模型与公共生成配置 | 聊天/标题/翻译/压缩/嵌入模型；建议回复配置、重试参数 | 分组读取和部分更新接口、模型存在性/能力校验 |
| 1 | 提供商与模型 | 提供商增删改、启用、地址、模型列表、能力、连接测试 | 专用管理 API；密钥仅返回 hasCredential/掩码，新密钥写入不回显 |
| 2 | 扩展 | 模式注入、世界书、快捷消息的编辑/导入/排序及绑定 | 当前只提供列表摘要与绑定；内容管理接口缺失，保持世界书正文原样 |
| 2 | 搜索/MCP | 配置、服务启停、测试、工具列表与审批策略 | 当前只能选已有服务/部分开关；MCP 连接状态及服务配置管理缺失 |
| 2 | 记忆/知识库/技能 | 助手绑定与开关、记忆查看管理、文档上传/索引状态/删除 | 对应 Web DTO、API、独立管理页面；模型调用仍由手机执行 |
| 2 | 建议与灵感 | 建议配置、插入模式、暂停刷新、反馈、灵感卡控制 | Web 目前主要是建议按钮，非完整本体控制面板 |
| 3 | 语音/翻译/图像/视频 | 先接入现有任务状态和结果，再做创建/控制 | 不应仅添加“设置开关”；需要任务、进度、取消与文件访问接口 |
| 3 | 日志/统计/备份 | 请求统计、脱敏日志、导出；备份状态及受控操作 | 当前没有管理页面/API；整库恢复/清空应后置并要求独立确认 |

通过 Web 发起的共享设置变更应在手机界面立即反映；手机修改也应通过 SSE 回写浏览器。浏览器不能把完整设置对象 PUT 回服务器，否则容易覆盖手机并发修改，并重新引入凭据泄露。

## 设置的保存范围

| 范围 | 示例 | 建议规则 |
| --- | --- | --- |
| 手机共享 | 模型、提供商、助手生成参数、记忆/知识库绑定、工具权限 | 明示“影响手机及所有连接的浏览器”，服务端保存 |
| 当前浏览器 | 语言、主题/CSS、侧栏宽度、工作台布局、快捷键覆盖 | 本地保存；按服务实例区分，不混入手机配置 |
| 可跟随手机的展示偏好 | 字号、代码折叠/换行/行号、思考展示、滚动、发送方式 | 默认跟随；显式“仅此浏览器覆盖”，提供恢复跟随 |
| 当前会话 | 系统提示词覆盖、注入绑定、工作区模式 | 放聊天页“会话设置”，清楚显示继承值和覆盖值 |
| Android 设备专属 | 权限、电池优化、通知渠道、SAF 文件夹授权、系统语音、安装/更新 | Web 显示状态和操作指引，必须由系统处理的授权留在手机 |

已有 localStorage 主题与语言应保留兼容；新增共享外观编辑不能在迁移时覆盖用户现有 Web 主题。

## 页面结构建议

第一版设置页：桌面使用左侧分类导航+右侧编辑区域，窄屏改为分类列表进入子页。

1. `/settings/browser`：外观、显示、输入、语言；展示本地/跟随手机的状态。
2. `/settings/assistants`：当前助手基础、提示词、生成参数、工具绑定；复杂助手管理可后续扩展子路由。
3. `/settings/models`：公共默认模型、提供商与模型管理入口。
4. `/settings/connection`：连接状态、重连、版本/能力、当前会话、退出登录；后台限制提示。

后续增加 `/settings/extensions`、`/settings/services`、`/settings/data`。知识库文档管理、工作区文件/终端、图像/视频任务、统计应做功能页，从设置页或导航进入，不堆成巨大设置表单。

聊天输入区保留常用模型/推理/搜索/MCP 快捷选择；侧栏新增稳定的设置入口。会话设置留在会话菜单，避免误改助手默认值。

## 实现约束与验收

- 使用模块化 DTO/明确字段白名单。系统提示词、世界书正文等可编辑内容按需读取，不塞入面向所有会话的高频 settings SSE。
- 增加版本/能力接口，让浏览器判断后端支持哪些配置；不支持的项应解释原因，不能假保存成功。
- 更新采用字段级 PATCH 或明确动作接口，服务端校验范围、UUID、模型能力和关联数据，返回规范化结果。
- 表单草稿与实时推送分离；有未保存编辑时收到远程变更应提示冲突，不能覆盖草稿。使用版本号/If-Match 或等效机制防止多人覆盖。
- 涉及凭据、执行能力、整库数据的管理接口需单独设计访问控制。当前 Web 密码是单一访问级别，不能假定已有管理员/只读角色；未启用鉴权时不宜直接开放凭据管理。
- 保存失败保留输入；SSE 恢复后重新对账；提供明确的作用范围、保存状态和恢复默认语义。
- 测试覆盖手机→Web、Web→手机、双浏览器并发、断线重连、过期登录、关闭重开、未知字段和敏感数据不回传。
- 上轮发现的后台停滞仍是重要访问可靠性前置问题，应先单独复现定位，再承诺长时间远程管理可用。

## 代码依据

- `web-ui/app/routes.ts`：当前路由仅首页和会话。
- `app/.../web/routes/SettingsRoutes.kt`：现有九组选择/开关写入入口。
- `app/.../web/dto/WebSettingsDto.kt`、`web-ui/app/types/settings.ts`：现有安全投影与前端契约。
- `web-ui/app/components/theme-provider.tsx`、`app/i18n.ts`：浏览器独立持久化。
- `web-ui/app/components/extended/conversation.tsx`、`components/markdown/markdown.tsx`、`routes/conversations.tsx`：滚动、代码和建议的实际消费路径。
- `app/.../data/model/Assistant.kt`、`data/datastore/PreferencesStore.kt`、`ui/pages/setting/SettingPage.kt`：Android 设置范围。

推荐下一阶段：设置页骨架与范围标识 → 接通已下发显示字段 → 助手基本配置/会话设置 → 默认模型/提供商管理 → 扩展、知识库和服务管理。
