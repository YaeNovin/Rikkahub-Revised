# 背景与聊天输入区修复

- 助手设置按本次修改的字段合并最新状态，避免快速调整背景、渐变和其他设置时相互覆盖。
- 选择本地背景后复制到应用管理的 backgrounds 目录，检查非空文件并显示保存状态；图片读取失败会在设置页提示。
- 替换助手图片时不再提前删除旧图片，避免破坏其他助手或全局背景共用的文件。旧文件保留供文件管理处理。
- 选择图片或重新启用渐变时，若原不透明度为零或无效值，则恢复到 100%；已有有效不透明度保留。
- 全局背景覆盖聊天时，助手背景仍按原设计禁用。助手设置提供“关闭全局背景覆盖，使用助手背景”入口。
- 启用或选择全局背景时，若页面样式为不透明，则改为半透明以显示背景；应用到聊天仍由原有独立开关控制。

## 输入框与 Dock

输入文字、附件、底部工具按钮和发送按钮共享一个外层表面，模糊只绘制在背景子层。删除独立 Dock 的折射染色与重复模糊层，保留原有按钮和布局。

高级外观中的“聊天输入区（输入框与 Dock）”提供统一的不透明度、虚化开关和半径，性能控制也共用输入区开关。没有背景或设备不支持实时模糊时保留普通透明表面。

首次升级时，如果此前只有 Dock 开启虚化，则将其半径和不透明度迁移到输入区；已有输入框虚化配置优先保留。此迁移只执行一次，不影响背景、助手、会话及其他配置。

## 后续特效渲染检查

- AGSL 输出改为预乘透明颜色，避免低透明度时颜色发亮；角度投影按实际像素尺寸计算，与 Kotlin 渐变保持一致。
- 两种引擎共用周期相位，修复非整数倍运动在基础周期边界处的跳变，以及 AGSL 原先整小时回绕造成的跳变。
- 渐变计时仅在绘制时读取；界面暂停和停止动效时保留相位，减少每帧重组。遵循系统减少动态效果设置时，配色过渡也会关闭。
- 顶栏、气泡和玻璃组件使用不附加主题染色的背景模糊，表面只显式绘制一次染色层；顶栏模糊半径为 0 时跳过模糊处理。
- 顶栏、卡片、输入区及弹窗会在表面染色足够深/浅时重新选择文字前景色，避免沿用图片前景色导致不透明面板文字消失。
- 修复 Shimmer 未完整扫过组件左侧的问题，并将逐帧动画状态读取移至绘制阶段。
- 空尺寸和非有限数值在渲染入口降级处理，避免无效半径、透明度进入图形 API。

AGSL 的着色器编译及 GPU 实际显示仍须真机验证；JVM 测试验证数学、兼容分支和状态策略，不替代截图与滑动体验检查。

## 验证边界

高级外观设置中的卡片/列表不透明度已独立分组，只有助手背景时也可调整。无可用背景的弹窗透明度和模糊滑块禁用；性能估算不再把半径为零的输入区和顶栏计为实时模糊。

滑块忽略较旧的保存回写，禁用或保存失败时丢弃待提交的调整。外观和显示设置落盘成功后再公布新值，失败时显示错误。

背景强调色在应用界面层提取，切换页面不会取消；未完成的配置可在下次启动继续提取，失败可在设置页重试。异步结果只写回仍启用、来源未变化且未已有颜色的配置。

AGSL 编译或渲染失败后，本次运行统一回退 Kotlin，并在高级外观页面显示黄色说明；保留用户的后端偏好，重启后重新检测。
