# 液态玻璃

入口：设置 → 偏好设置 → 高级外观 → 液态玻璃材质。

## 预设和高级选项

- **柔和**：低高光、较薄边缘和轻微折射。
- **标准**：兼顾边缘厚度、反光和背景清晰度。
- **通透**：降低主题染色，增强边缘高光和折射。
- **自定义**：可调整高光、主题染色、边缘厚度、内侧阴影、边缘折射距离。修改任意高级参数时，以当前预设为基础进入自定义。

各区域原有的不透明度和模糊半径仍独立控制，切换材质预设不会覆盖这些数值。主题染色为 0 时采用中性玻璃，不再固定混入蓝色。

## 应用范围

已选择液态玻璃的弹窗、侧边栏、卡片和选择器共用材质参数。聊天输入区的选项集中在“聊天输入区（输入框与 Dock）”：表面样式（半透明/磨砂/液态玻璃）、输入区动态效果、模糊强度与不透明度。原先分散的“用于聊天输入区”“输入框背景虚化”和性能卡中的输入区开关已合并，沿用既有配置值。

页面内的玻璃组件通过 Haze 共享底层背景，滚动时由 Haze 同步坐标，不再在每个卡片内回放壁纸图层；普通透明卡片及嵌套子控件不重复铺画原始背景。AGSL 仅处理取样后的背景边缘，文字与交互内容不进入效果层。

聊天输入区不再使用弹窗式独立壁纸：输入、附件和 Dock 共用一个表面，普通模糊和玻璃都取样实际聊天场景（助手/全局背景和滚动消息），输入文字与按钮不进入取样源。无壁纸时也可模糊后方消息。页面内其他卡片仍只取样背景；抽屉和弹窗的隔离策略不变。

输入区不透明度范围为 0%–100%，Dock 使用同一数值，不再读取旧的独立 Dock 不透明度。关闭输入区动态效果只暂停模糊、折射和玻璃边缘绘制，保留不透明度；不会突然变成不透明卡片。高模糊强度会让后方文字变模糊，需清晰透视时将模糊降为 0 并降低不透明度。材质切换原子更新两个相关设置记录，不更改其他偏好、助手或模型。

侧边栏、底部抽屉、弹出菜单和对话框恢复为液态玻璃改造前的独立背景绘制：按容器尺寸绘制配置的图片或渐变，继续使用各自的不透明度和虚化参数，不依赖跨窗口图层或 AGSL 折射。弹窗保留不透明底层，避免后面的聊天文字穿透。背景未加载或失败时，文字和图标使用与实际底色匹配的颜色。

高光和阴影位于形状边缘；文字、图标、按钮均不参与背景折射。全局背景本身不再叠加整页玻璃染色。

## 渲染和性能

- **自动**：符合条件时启用 AGSL，其他情况使用标准效果。
- **标准**：使用 Compose 背景模糊与边缘绘制。
- **AGSL**：Android 13+、硬件加速、圆角或矩形的可见组件可使用背景边缘折射。不支持的选项置灰并显示黄色说明。
- 每次最多三个可见玻璃/模糊组件参与高级背景处理，超过限额时保留普通表面和边缘效果。
- 超过 180000 平方 dp 的组件跳过折射；正文中心不做折射。
- 自适应性能默认开启，滚动、按压、键盘显示和省电时暂停折射，降低模糊与高光强度。关闭自适应仍保留设备、面积和数量限制。
- AGSL 失败后本次运行改用标准玻璃，重启后重新检测。原始设置保留。

## 验证边界

JVM 测试覆盖预设、参数约束、序列化、屏幕取样偏移、兼容降级及性能限额。QA 编译检查 Android/Compose 接入。

AGSL 是运行时编译的着色器，实际 GPU 显示、跨窗口背景对齐、滚动/键盘时的帧率和内存仍需真机测试，不能仅凭 Kotlin 编译判定显示效果通过。

## 思考与工具摘要

思考和工具调用摘要共用富内容表面设置（描边/半透明、表面透明度），统一圆角、细边框和摘要栏底色。文字按组件实际表面重新选择颜色，避免亮色图片对应的黑色文字落在深色摘要卡上；摘要正文、标题、图标使用同一套可读性配色。

思考进行中且未完整展开时，摘要栏显示渐变流光；完整展开或生成完成后停止。关闭富内容增强效果、系统关闭动画、省电、后台和离屏时不运行流光。流光在文字下方绘制，完整思考正文不参与动画，导出图片不渲染流光。
