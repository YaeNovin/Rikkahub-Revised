# WebUI 后续同步检查

日期：2026-10-06。依据当前工作区 Android 模型、Web DTO、管理接口、React 页面和消费字段进行静态核对。此次只新增检查记录，不修改业务代码，不重新安装 APK，也不把此前真机结果当作本轮测试结果。

## 结论

六类独立设置页已经建立，供应商/搜索/MCP/Skills、非图片默认模型与提示词、标题生成、重试、助手上下文压缩、发送键、Web 访问保护已经接入。后续应优先消除“能保存设置但 Web 聊天不遵循”的差异，再补助手与会话编辑、提示词资源和知识管理，不需要重做设置页骨架。

## 已实现，不再重复排期

- 模型供应商及聊天/嵌入模型管理、获取模型列表；搜索服务配置；MCP 配置/工具同步；Skills 正文增删改和助手绑定。
- 非图片默认模型/提示词、标题生成参数、生成失败重试、按助手自动压缩上下文。
- Enter / Shift+Enter 发送设置；浏览器主题、配色、语言、CSS；浏览器自动重连偏好。
- Web 端口/本机与局域网监听/密码/重启/停止，后台权限说明、当前会话退出。
- 聊天发送/停止/重新生成、消息编辑与分支、工具审批、会话搜索/重命名/移动/文件夹、附件、Markdown 导出和部分预览。

这些项目已存在页面与接口，不表示与本体每个高级操作和交互细节完全一致。

## 后续功能页与连接改进

- 语音识别/朗读和语音服务配置：先设计任务/播放状态，再增加入口。已有音频消息播放不是 TTS/ASR 管理。
- 收藏、使用统计、脱敏请求日志和诊断：补只读列表与筛选，再考虑管理操作。
- 备份/导出：先状态与导出；整库恢复、清空和目录授权独立处理，不放进普通设置保存。
- 连接与访问：当前主要展示 origin/协议和重新加载按钮；建议增加真实连接状态、最后收到事件时间、最近错误、服务端版本/能力和重连状态。缓存设置与“服务运行中”不能替代健康检查。
- 登录会话管理：目前支持当前会话退出；活跃浏览器列表、逐个撤销/全部退出可作为后续增强，不属于现有本体功能必需逐项照搬。
- 多浏览器助手切换：目前使用共享 `settings.assistantId`。需明确“跟随手机”与“仅当前浏览器导航”的产品选择；后者需要查询和路由配合，不能只改前端状态。

## 保留的范围

- 图片/视频模型管理及对应生成配置按用户此前要求暂不接入；不要误列为本轮遗漏。媒体结果播放/展示与模型管理是不同事项。
- Android 通知、厂商电池策略、局域网系统权限、SAF 目录授权、系统安装更新应由手机完成；Web 展示状态与指引。
- OAuth 目前明确留在手机授权，浏览器不读取令牌。
- Web 主题/CSS/语言及连接偏好可独立保存；不应机械复制 Android 材质、背景或主题 ID。业务参数继续以手机为唯一来源。

## 建议批次与验收原则

1. 显示字段、LaTeX、建议插入/显示行为：先让已有设置确实生效。
2. 更多弹窗完整助手编辑 + 会话系统提示词 + 翻译结果/入口。
3. 提示词资源、工作区基础信息/模式、记忆与知识库管理。
4. 服务测试、渲染/导出、语音、统计与诊断等独立功能。

每批都验证手机→网页、网页→手机、两个浏览器并发修改、刷新后持久化、草稿冲突保护；设置页验收和聊天实际效果验收必须分别完成。继续使用分组白名单/写入校验，不把完整 Settings、凭据或大段资源正文直接推入公共 SSE。
