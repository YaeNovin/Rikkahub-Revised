# 文字配色

更新：2026-11-19。以下描述开发源码；正式版能力以对应发行说明为准。

## 模式与来源

设置入口：设置 → 偏好设置 → 高级外观设置 → 文字配色。

- 跟随主题：使用主题文字，不从图片提取前景色。
- 自动清晰：根据页面背景和组件表面选择可读的前景。
- 跟随应用背景：从当前实际显示的助手或全局图片、渐变提取有代表性的色调；没有有效来源时安全回退。
- 跟随手机壁纸：读取系统 WallpaperColors；可用性取决于 Android 版本与厂商 ROM。无法获取时尝试可用的系统动态颜色或安全回退，并明确来源。

应用图片在后台采样并通过 Google Material Color Utilities 的 Celebi 量化与 Score 选择种子。滤除透明、无效、极小和过暗/过亮噪声，优先选择有实际像素支持的彩色家族，不凭空填入默认蓝色。源图按可见裁切分析，避免未显示的图片两侧主导取色。

Android 限制或 ROM 行为可能使壁纸原图与系统颜色不可用；不绕过系统权限读取壁纸文件。可通过系统图片选择器为壁纸模式提供原图，保留本地 URI 授权并绑定可用的壁纸身份；换壁纸后需核对原图是否仍对应。系统回调、返回前台和配置变化触发后台刷新，避免在滚动时重复量化。

## 显示与对比度

文字取色覆盖页面、设置、用户气泡和消息正文，以及继承该前景的组件。卡片、弹层、输入框等按自己的表面背景重新校正，避免将页面的深色文字直接用于深色卡片。HEX 色块、语法高亮和作者明确指定的图形颜色保持各自含义。

使用 HCT 保留色相并调整色度和明暗。当前实验色度在已有目标上乘以 `1.11`，即约增加 11%；达不到对比度时仍优先保证可读性。复杂图片依据有限背景样本估算，不能保证每个像素位置都达到统一对比度。

已移除为增强对比度而加的文字描边/阴影，改用前景颜色校正与约 10% 字重提升；输入中的原始内容和复制结果保持原样。嵌套表面避免重复累加字重。

## 稳定性与验证

背景样本、色种与前景计算复用缓存。切换配色不更换页面身份或滚动状态，背景解码不阻塞 UI。恢复应用时先采用可用缓存，后台更新；不通过重建整个导航树刷新颜色。

生产计算入口包括 `TextColorPalette.kt`、`WallpaperTextSeed.kt`、`TextReadabilityWeight.kt` 和 `material3/ImageColorAnalysis.kt`。自动化设备入口见 `scripts/verify_appearance_modes.py`、`verify_palette_state.py`、`verify_dark_appearance.py` 及[脚本说明](../scripts/README.md)。

颜色算法测试中的壁纸 PNG 使用[合成夹具](../material3/src/test/resources/wallpaper-reference/README.md)，不上传用户原图。已有真机记录只覆盖各次记录中的设备、背景与主题组合；其他 ROM、动态壁纸和每个局部背景仍需单独验证。早期阶段性修复与安装记录已移入本地归档。
