# 文字配色模式

## 本轮实现

入口：设置 → 偏好设置 → 高级外观设置 → 文字配色。

- **跟随主题（关闭文字取色）**：恢复主题文字，不从应用背景或手机壁纸取色。不会关闭背景或修改组件配色来源。
- **自动清晰**（默认）：在启用背景的页面根据背景样本与组件已有底色选择深色/浅色文字；没有背景的普通页面沿用主题文字。
- **跟随应用背景**：从当前页面实际采用的助手图片、渐变或全局背景提取色调，通过 HCT 生成有可辨色调的文字，并校正明暗。没有背景时沿用主题文字，没有有效彩色样本时使用自动清晰。
- **跟随手机壁纸**：优先使用系统提供的桌面壁纸颜色；Android 12 及以上在壁纸颜色不可用时尝试系统动态配色，再不可用则回退到自动清晰。Android 8.0 不支持，选项置灰并显示黄色说明；Android 8.1 及以上可使用，但实际可用性取决于系统。不会申请读取壁纸图片或存储的权限。

设置独立于“使用背景强调色”。旧设置自动使用默认值，不需要数据库迁移。

## 配色切换修复

- 文字取色不再改写 `outline` 和 `outlineVariant`；按钮填充、描边、背景等仍由组件主题控制。
- 显式选择动态颜色会退出背景强调色；启用背景强调色会退出动态颜色；选择、保存或导入主题会退出两者，确保手选主题立即生效。旧配置中同时开启两者时继续兼容原有背景强调色优先级，下一次主动选择会消除冲突。
- 主题选择页提供“改用手选主题”入口；即使当前没有全局背景，也可以关闭之前已启用的背景强调色。
- 配色更新使用最新设置上的字段变更，避免主题选择把刚改好的文字模式和背景设置覆盖回旧值。
- 用户/助手消息气泡按实际表面选取文字，向 Markdown 正文与公式显式传递一致的前景色；Markdown 内联样式的缓存随主题、文字样式和字体缩放更新。

## 渲染约束

- 只改变正文、次要文字及使用对应前景色的图标，不改变既有图片、遮罩、表面颜色、透明度、虚化、AMOLED 背景或渐变色。
- 保留链接、错误提示、代码语法等语义配色；它们的独立配色属于后续阶段。
- 颜色不会直接使用吸取到的原色。HCT 候选保留最多 32 的色度，并按最终 RGB 对比度逐步校正明暗；可满足时以普通文字 4.5:1 为目标。复杂明暗背景可能不存在对所有区域都合格的单一前景色，此时仅在不减少黑白基准的达标区域数、且不降低最差对比度时保留彩色文字，否则回退到深浅文字，不强制增加遮罩或描边。
- 组件根据已经叠加的原有底色重新计算文字颜色，避免将浅背景上的深色文字直接用于不透明深色弹窗。输入框、顶栏、卡片、思考/工具摘要和独立预览菜单共用取色逻辑。
- 图形全屏预览接入全局背景样本，记忆全屏预览继续使用隔离表面的前景逻辑；不重写 SVG/HTML 中作者明确指定的颜色。
- 图片采样在后台进行，切换文字模式复用样本；组件缓存前景计算，不随聊天流式输出或滚动反复生成 HCT 色。渐变使用稳定样本，不随每帧动画跳变文字颜色。
- 手机壁纸模式监听系统颜色变更，并在返回应用、系统配置变更时刷新；退出该模式后移除监听。少数系统可能只在返回应用时提供最新壁纸颜色。

## 后续计划（本轮不实现）

1. 自定义文字模式：复用已有 HCT/HEX 取色器，为正文和次要文字提供手动设置与恢复默认。
2. 文字对比度档位：与当前会改变整套主题的“配色对比度”区分，独立控制前景目标。
3. 可选的字形描边/阴影：仅影响文字轮廓，由用户启用，不修改背景遮罩。
4. 局部取样：依据组件位置与背景裁切估计实际底色，增加切换阈值和稳定时间，避免滚动、动画时颜色闪烁。先验证性能收益与开销，再接入。
5. 精细语义角色：链接、代码、引用、禁用文字等独立校正，兼顾已有主题和渲染器颜色。
6. 扩大设备回归：Android 8.0/8.1、12 和更新系统，厂商 ROM、静态/动态壁纸、多窗口、深浅模式切换、透明/液态玻璃表面，以及图片/渐变和记忆预览。
