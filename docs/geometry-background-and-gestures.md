# 几何预览：背景、双指缩放与安全区

开发工作区改动，未重新构建/安装 QA。针对手机截图中顶部缩放按钮贴近状态栏/前置摄像头的问题，同时补齐观赏性渲染的已有背景设置适配。

## 背景规则

| 渲染 | 聊天内 | 全屏预览 |
| --- | --- | --- |
| `sigil`（法阵） | 当前聊天背景有效、页面非不透明模式时透出背景 | 复用“全局背景应用到全屏预览”设置及底部背景切换按钮 |
| `pattern`（曼陀罗、玫瑰线、分形等） | 同上；清除 p5 画布底色，而非只将 WebView 背景改透明 | 同上；关闭背景设置后恢复 JSON 的 `background` 底色 |
| `math_plot` / `math_plan` / `jsxgraph` | 保留坐标、网格及独立底色 | 不提供背景切换，不透出背景 |
| `terminal` / ANSI / xterm | 保留终端底色 | 保持原有终端行为，不应用全屏背景 |

背景图片/渐变仍由原生已有背景组件负责，不将 URI 交给模型或 WebView，也不放宽离线 CSP、网络/文件访问。背景开启时，标题、状态说明、操作区也透明，不再保留横贯页面的固定深/浅色条；文字复用原生背景可读性前景色，并附加轻量对比阴影。右下角原生工具栏复用既有表面样式及 `pageSurfaceOpacity`，不强制使用 94% 实色底，也不重复加载背景图片。背景关闭时恢复原底色、文字和工具栏外观。背景切换不重载页面、不重新生成路径、不重置缩放、平移、种子或动画时间。

全屏背景继续独立于聊天助手背景，沿用已有全屏设置，不把当前助手背景误当成全局预览背景。

## 手势与布局

- 数理、法阵、纹样统一移除 `＋` / `－` 按钮，使用真实双指捏合缩放；缩放围绕两指中心，双指移动会保持锚点关系。
- 全屏可单指拖动平移。聊天内单指不平移图形，保留原生对话纵向滚动协调；双指由 WebView 内容控制，原生网页缩放关闭，避免整个页面和文字一起放大。
- 法阵/纹样缩放范围仍为 0.5–3；数学视口保留既有坐标/采样范围限制。
- 保留“重置”“播放/暂停”“变换”必要操作，移至绘图下方。支持键盘 `+` / `-` 缩放、`0` / `Home` 重置；只在键盘焦点时显示可访问性焦点轮廓。
- 全屏 WebView 显式避让 `safeDrawing`、即使系统栏隐藏时的状态栏/导航栏及 `displayCutout`。为既有原生底部返回/背景/调试工具条保留 56dp 区域，HTML 控件与工具条不叠放。
- 去除几何预览卡片外描边、额外内边距、画布圆角边框及 HTML 按钮描边；源码模式、普通代码块和终端原有外观不变。
- 缩放/平移同步作用于法阵、纹样和星尘覆盖层，保留原来的动画预算、离屏暂停和导出冻结机制。

全屏返回依然回到当前对话。背景开关变化不改变相机；打开新全屏预览仍按源码初始化。单图 PNG 保存沿用现有 WebView 截图语义，不额外捕获其背后的原生壁纸；透明画布可保留透明区域，整段聊天导出仍由原有原生合成流程处理。

## 缓存和兼容性

缓存目录升级为 `webview_content_safe_v5`，避免旧模板缺少新的手势脚本、渲染器类型标记、CSP 条目或继续保留实色标题/操作栏。旧预览链接可能提示过期，返回对话重新打开即可；没有删除聊天源码或主动清除旧缓存。

`selfManagedPreview` 只决定是否跳过通用图形平移注入；背景能力单独判断，避免把法阵/纹样与终端、函数图混为一类。通用 SVG、图表和 HTML 静态预览保持既有路径，不注入作者脚本。

## 源码高亮

`math_plot` / `math_plan` / `jsxgraph`、`sigil` / `magic_circle`、`pattern` / `generative_art` / `p5_pattern` 等全部登记别名，源码显示时映射到原生 JSON 高亮。普通源码视图与“行号＋自动换行”视图均适配；标题上的渲染器名称、预览路由、复制、下载原文不变。JSON 键、字符串、数字、布尔值等沿用原有深浅色配色，数学表达式仍作为 JSON 字符串显示，不执行源码。

普通代码维持原有 4096 字符高亮上限；声明式渲染源码显式扩展到 32768 字符。超过 4K 的单块文本使用短暂防抖及后台解析，使用独立高亮器实例，避免跨线程共用可变语法匹配器；待结果返回前显示原文。内容/语言/主题不匹配的过期结果不应用。超出 32K 的渲染源码保留完整纯文本，不截断或突破上限。ANSI、终端和未知语言不被误当 JSON。

## 验证

- 本次应用 Kotlin 编译、80 项应用 JVM 测试和 57 项高亮模块测试通过，共 137 项。覆盖背景能力分类、HTML/CSP、全屏幂等转换、缓存、工具入口、手势归属、别名高亮、长源码边界及既有语言语法。
- `verify-geometry-appearance.cjs` 的 7 个场景通过，使用 Chromium CDP 多点触摸输入，而非直接调用缩放函数：放大/缩小、全屏平移、聊天内单指不平移、取消后恢复、横竖屏变化、键盘重置。
- 实际截图像素检查确认法阵和 p5 画布、标题栏、状态栏、操作栏均透明，关闭背景后恢复不透明；函数图始终保持不透明。检查宿主配色更新、非法 CSS 值拒绝，以及背景切换不重建画布/路径、不改变相机、不中断动画时钟。
- 背景栏与高亮增强另增加 `PreviewBackgroundChromeTest`、`RendererSourceHighlightTest` 及高亮模块 `ExtendedSourceHighlightTest`；验证宿主只传固定格式颜色、JSON 别名、真实着色范围、长文本限额和源码保真。完整高亮模块测试通过。
- 本次浏览器共 39 个场景通过：背景/触摸 7、JSXGraph/sigil 9、纹样 15、动态特效 8；未把之前轮次的其他场景计入此次总数。脚本语法及 `git diff --check` 通过。

先运行 `GeometryAppearanceTest` 生成生产 HTML，再执行 `node scripts/verify-geometry-appearance.cjs`。报告和截图位于 `app/build/reports/geometry-appearance/`。

桌面浏览器触摸验证不等于 Android 真实触摸分发；原生对话滚动、刘海/挖孔设备与系统栏动态显示时的安全区，以及原生 PNG 合成仍需手机复测。本轮没有连接付费模型、修改手机应用或重新安装 QA。
