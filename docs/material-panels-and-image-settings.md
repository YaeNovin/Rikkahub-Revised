# 云母独立面板、亚克力首次显示与生图设置适配

日期：2026-10-01。工作区修复，未覆盖安装新的常规 QA 包。

## 材质

- 原先独立云母表面只画一层 card 色，并只替换两个前景角色；子控件仍继承页面的旧表面色，而且上下文被标成“没有背景”。现改为独立面板拥有云母渐变底层，统一传递完整云母表面角色、可读前景和已绘制背景样本。侧栏、云母弹窗和底部面板共用这条路径；输入框的云母模式继续使用 card 层。
- 云母是明确选择的不透明材质，不重放壁纸，也不进行实时模糊。没有图片时仍有主题染色底层和卡片层次；不把“看不到壁纸”本身当作故障。
- 亚克力原先直接读取非响应式的 `View.isHardwareAccelerated`；初次组合早于窗口挂载时可能锁定无模糊分支。现于布局完成后刷新硬件状态，使实时输入区和浮层快照能够进入可用分支。
- 仍保留设备不支持、效果关闭、省电、无采样源时的回退；不擅自重置透明度、模糊强度或效果开关。透明度为 1、半径为 0 或背后没有细节时，不承诺明显的模糊变化。

## 模型搜索与参数面板

- 聊天、图片生成页共用的 ModelList 搜索框移除默认不透明 Surface，改用现有 AppearanceOptionSurface 和透明输入框；文字、占位符与图标跟随浮层前景。
- 图片参数的“基础选项／高级选项”导航复用外观化 SecondaryTabRow，浮层已有底色时不再叠一块默认实色。两个 Tab 的文本也继承当前材质。
- 生图设置每个横向参数页只有一个受约束的纵向滚动区。标题、聊天特有的开关／说明／图片模型选择、两个参数 Tab、所有参数及底部确认统一滚动。保留横向分页、模型能力筛选、参数编辑逻辑和各页滚动状态，不将分页器放入无限高度父滚动容器。
- 键盘弹出时缩小可用滚动窗口，不靠固定头部挤压参数区域。无聊天专用头部的图像生成页面也复用同一布局。
