# 灵感卡片、导航与搜索

## 灵感启动卡片

- 空白对话的灵感卡片单独处理输入，不受聊天建议的模型、预览或替换设置影响。空草稿直接填入；已有草稿先预览，再选择追加或替换。替换前验证草稿仍与用户查看时一致；不发送消息、不执行工具、不清除附件。
- 内置普通模式保留工作与日常模板；娱乐模式提供对白、场景、剧情、角色、相遇和日常模板，不预先运行世界书或隐式注入记忆。
- 复用快捷消息的 `{{变量}}` 解析与字面量替换。助手名、用户名自动填入，其他变量先填写后插入。最多 12 个变量。
- 全局默认显示 4 张，可调整为 1～8 张、关闭内置卡片、添加最多 40 张自定义卡片并指定适用模式。设置入口在「偏好设置 → 通用 → 灵感启动卡片」。
- 助手基本设置和空白聊天的管理按钮进入助手配置，可继承全局或单独配置。聊天长按固定/取消固定会为当前助手建立独立配置。换一组仅轮换未固定卡片，固定超出显示数量时保留配置，按固定顺序优先展示。
- 窄屏与大字体单列，常规宽度两列，大屏三列。键盘弹出显示紧凑横向卡片，不再占用固定比例的聊天高度。
- 「高级外观 → 灵感卡片外观」默认跟随富内容表面/描边/圆角；关闭跟随后可单独调整不透明度、描边和圆角。文字沿用已实现的取色与对比度处理，仅绘制当前页面背景上的表面，不在每张卡片内重绘壁纸。
- 所有新增配置有默认值，通过原有设置与助手序列化保存，不修改消息或数据库表结构。
- 管理弹窗草稿保存在页面 ViewModel 中，旋转屏幕保留编辑进度，不把整套自定义提示词写入系统状态 Bundle。取消后重新打开恢复已保存配置；变量填写值在配置变化时保留。
