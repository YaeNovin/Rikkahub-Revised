# Rikkahub Revised 2.4.8-revised.10

更新内容:

- 扩展 GPT、Gemini、千问、DeepSeek、MiniMax、Kimi、MiMo 和 GLM 的模型与参数适配，支持按填写的模型名称识别能力与图标；完善图片生成选项、Flare / Sunburst 切换，以及独立决策模型和聊天建议配置。
- 新增 DeepSeek 与火山引擎／豆包搜索，完善自定义网页与 X 搜索；增强 Gemini 内置搜索、图片搜索、网址内容读取及实验性会话支持，改善第三方供应商和不同连接方式下的工具兼容性。
- 修复发送后消息显示不及时、停止回答后消息丢失、停止按钮响应迟缓和部分提示词弹窗崩溃；改善长对话滚动、键盘弹出、页面返回、抽屉操作、冷启动与后台恢复的流畅度和稳定性。
- 优化深色模式及复杂壁纸下的文字取色、饱和度与对比度，并覆盖消息正文和用户气泡；新增可关闭的 HEX 色块和正文引号高亮，增强表格横向滚动、列对齐及搜索引用显示，保留粘贴源码与代码块原文。
- 重整系统日志的分类、条目和堆栈展开，完善请求记录、错误诊断和附件读取；扩展网页版独立设置、图片生成与交互卡片，并整理现行文档、离线资源及过时图片。

Updates:

- Expanded model and parameter support for GPT, Gemini, Qwen, DeepSeek, MiniMax, Kimi, MiMo, and GLM, with capability and icon matching by configured model name. Improved image settings, Flare / Sunburst selection, and dedicated decision-model and chat-suggestion settings.
- Added DeepSeek and Volcengine / Doubao search and improved custom web and X search. Expanded Gemini search, image search, URL reading, and experimental conversation support, with better tool compatibility across third-party providers and connection types.
- Fixed delayed sent messages, messages disappearing after stopping a reply, unresponsive stop controls, and crashes in some prompt editors. Improved long-chat scrolling, keyboard transitions, back navigation, drawers, cold starts, and recovery from the background.
- Improved wallpaper-based text colors, saturation, and contrast in dark mode and on complex backgrounds, including message text and user bubbles. Added optional HEX swatches and quotation highlighting, enhanced scrolling tables, column alignment, and search citations, and preserved pasted source and code blocks.
- Reorganized system logs with categorized entries and expandable stack traces, and improved request records, error diagnostics, and attachment reading. Expanded independent web settings, image generation, and interactive cards, and refreshed documentation and offline resources while removing obsolete images.
