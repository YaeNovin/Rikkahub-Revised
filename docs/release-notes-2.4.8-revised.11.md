# Rikkahub Revised 2.4.8-revised.11

更新内容:

- 完善删除线、任务列表、上下标、邮箱和自动链接的显示，改善引用及消息网页预览的一致性，并保留粘贴源码和消息换行。
- 改进简谱的显示大小、自动换行和全屏查看，优化终端输出的滑动与加载失败提示，移除占用预览空间的常驻说明。
- 修复普通链接和搜索引用的点击、长按问题，新增应用内网页预览，改善链接附近的文字选择以及预览返回后的阅读定位。
- 优化 Web 服务器的后台访问说明，统一进入系统设置的入口。

Updates:

- Improved strikethrough, task lists, superscripts, subscripts, email addresses, and automatic links. Made citations and message web previews more consistent while preserving pasted source and message line breaks.
- Improved music-score sizing, wrapping, and full-screen viewing. Refined terminal scrolling and load-failure messages, and removed persistent hints that occupied preview space.
- Fixed taps and long presses on links and search citations. Added in-app web previews and improved nearby text selection and reading-position retention when returning.
- Clarified background access instructions for the Web server and unified the system settings shortcut.
