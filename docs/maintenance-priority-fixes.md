# 中高优先级维护：第一批

本批覆盖删除撤销、全文搜索分页、知识库检索完整性和后台文档导入。没有修改数据库版本或执行破坏性数据迁移。

## 行为变化

- 历史页删除：撤销提示结束前仅隐藏列表项，对话、附件、收藏及其他关联记录保留；撤销或离开页面取消待删除操作。提示关闭/到期后提交数据库与全文索引删除，再清理附件。重复点击不会重复提交。此机制是撤销窗口保护，尚未提供长期回收站。
- 全文搜索：每页 50 条，使用额外一条判断是否有后续结果，提供“加载更多”。排序包含稳定的行 ID；查询/排序变化清空分页并取消旧请求，旧请求即使迟到也不能覆盖新结果。加载失败保留已加载结果并支持重试，重建索引结束后重新搜索。
- 知识库：按分块 ID 每批读取 128 条，扫描全部可检索分块，只保留得分最高的少量结果；词法检索不读取向量二进制。嵌入模型分组使用所有已索引分块的去重元数据，消除原先 1,200/2,000 条候选限制。这里实现的是内存有界的精确扫描，不是近似向量索引；大型库查询耗时仍需进一步测量。
- 文档导入：将不超过 20 MiB 的输入保存到应用私有目录，由 WorkManager 调度并限制并行导入数量为 2。离开页面不会取消已入队任务；系统中断可使用 WorkManager 持久任务恢复。界面提供等待、分块进度、取消和重试。
- 导入重试：复用内容、位置及模型一致的已完成分块，保留分块 ID；损坏、非有限或属于其他模型的向量重新生成。重试会使用当前所选模型创建新的任务请求，单次后台执行及其系统恢复使用入队时记录的模型 ID。已禁用或删除的模型会报错，不静默替换。
- 导入删除：删除/取消后的文档不会被晚到的结果重新插入。失败和取消时保留源文件用于重试，导入成功或删除记录时清理临时源文件。旧版中断记录、缺失调度记录会显示可处理的失败状态。

## 回归验证

JVM 回归覆盖撤销/页面取消/重复删除/提交中取消、超过 50 条结果的分页/请求竞争/失败重试，以及超过 2,000 个分块的召回、全局排序和导入分块复用。另提供 Android 数据库集成测试，覆盖实际分页查询、模型枚举、取消/删除写入保护和删除事务回滚。

运行命令：

```powershell
.\gradlew.bat :app:testDebugUnitTest --tests '*PendingConversationDeletionsTest' --tests '*MessageSearchPagerTest' --tests '*KnowledgeChunkRankingTest' --tests '*KnowledgeImportCheckpointTest' --tests '*KnowledgeBaseToolsTest' --tests '*KnowledgeCitationFilterTest' --tests '*KnowledgeDocumentPreviewTest' --tests '*ConversationPagingLoadTest' :app:compileDebugAndroidTestKotlin
```

验证边界：Android 集成测试的编译不代表设备执行通过。系统回收后的 WorkManager 恢复、SAF 授权、真实嵌入接口及触摸交互仍需设备验证。已提交但未落盘的那一批嵌入请求在进程终止后可能重发；不承诺供应商侧恰好执行一次。
