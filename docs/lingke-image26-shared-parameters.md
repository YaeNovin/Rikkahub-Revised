## 版本与请求

- “模型版本”提供模型默认、Flare（标准版）、Sunburst（增强版）。
- 手动生成、聊天生图和图片编辑共享 `GptImage26Options.version`，随参数状态保存与恢复。
- 明确选择的版本优先于旧模型显示名称的 Flare / Sunburst 推断；默认保留旧推断，否则使用 Flare。
- 切换版本只改变 `params.version`，保留用户配置的传输模型 ID（例如 `tt-image-2.6`）。无需创建两个供应商模型。
- 仅媒体协议显示版本控件；普通供应商的分立模型继续使用各自模型 ID，不自动发送该版本字段。

媒体请求使用原生 GPT Image 参数构造器后封装为 `{model, prompt, params}`，避免独立白名单静默删除压缩、审核和 SVG 等参数。生成与编辑均复用同一实现。`notify_url` 如通过自定义参数传入，仍置于顶层。

本轮不改变已支持的媒体创建、状态轮询和图片下载路径。原 `/images/generations`、`/images/edits` 显式路径覆盖继续可用。
