# Web 独立设置、交互问答与浏览器图片生成

## 设置范围

- Web 首次启用时复制现有配置，随后写入独立的 `datastore/web_settings.preferences_pb`；手机继续使用 `settings.preferences_pb`。
- 模型供应商、模型定义、搜索服务及选择、MCP 配置实时共享；Skills 文件仍共享。
- Web 助手选择、助手参数与绑定、发送键、默认模型、标题/提示词、生成重试、压缩配置、提示词资源副本不再写入手机设置。外观、语言、连接偏好和图片页参数保存在浏览器。
- Web 配置是一份独立于手机的 Web 档案，多个浏览器仍共享该档案；浏览器本地外观与安全偏好各自保存。
- Web 安全页提供当前浏览器闲置自动退出及当前会话退出，手机的监听端口、访问密码、访问范围与服务启停改为手机管理。手机访问保护状态仍用于认证，不能用独立偏好绕过认证。
- 聊天历史、工具问答答案、压缩摘要和图库仍是共享业务数据；隔离的是设置，未创建另一套聊天数据库。
- Web 发起的聊天、问答续写、标题生成、手动压缩使用 Web 配置。消息模板按请求中的助手模板渲染，避免同一助手 ID 的手机模板覆盖 Web 副本。

## ask_user 与上下文

- 保留文本、单选、多选、滑块、评分、确认、日期、时间及富选项展示，补充命名条件图与条件组解析。
- 草稿通过 `/api/conversations/{id}/ask-user/draft` 写入原生 `AskUserInteraction`；逐题确认计时由手机服务端生成并校验，网页按返回的服务端时间校正显示。
- 确认超时仅将相应题目置为拒绝，不自动取消整个表单。提交前等待草稿保存，刷新恢复草稿，保留错误与重试入口。
- `/context` 复用原生上下文分类计算与请求快照校准，显示容量、剩余、分类、最近供应商输入统计及摘要。
- 自动处理状态由会话 SSE 的 `processing` 事件推送；Web 显示处理中动画。`/compress` 支持摘要目标 Token 与附加要求，拒绝同会话重复压缩，保留历史消息。
- 手动摘要带 `manuallyRequested` 标志，关闭自动压缩时也可在后续请求中使用。

## 浏览器图片生成

- 入口：聊天侧栏 → 图片生成；支持生成、参考图编辑、按模型能力显示参数、停止请求、查看/下载结果、历史检索、文件夹创建/移动/解散、复用提示词和参考图片。
- 供应商管理允许新增/编辑图片模型，视频模型仍保留在手机端管理。
- 浏览器按选定模型获取短暂连接配置，直接请求供应商，解码 Base64 或下载返回图片。供应商 API Key 不进入设置 SSE、localStorage 或 IndexedDB。
- 支持现有 OpenAI 兼容图片接口、multipart 图片编辑、xAI JSON 编辑、Seedream 参考图请求与 Google/Gemini 图片接口；参数能力来自原生供应商实现。
- 生成结果先写入浏览器 IndexedDB，随后通过 `/api/images/import` 回传。手机只验证图片文件并写图库，不代理供应商生成或下载请求。断线后可刷新并重试落库，重复保存同一标识与图片返回同一记录。
- 图库使用现有 `GenMediaEntity`、文件目录和文件夹，软件本体可直接读取结果。

## 验证与限制

- 前端 TypeScript 检查、生产构建、15 项单元测试通过。
- 5 项 Edge 无头浏览器测试通过：登录与设置流程、会话断线重连、预览隔离、图片直连/刷新恢复/重试落库、问答草稿/逐题倒计时/手动压缩。
- Android Web 相关 17 项单元测试通过；独立 QA 包真机 2 项测试通过：设置持久化隔离、真实 Ktor 图片接口认证与图库落库/重复提交去重。测试会恢复原配置并清理测试图片。
- 测试包名为 `me.rerere.rikkahub.revised.websettingsqa`，ADB 使用覆盖安装且未清除数据。没有更新原来的 `me.rerere.rikkahub` QA 包，也没有替换此前存放在 `sign` 的正式版。
- 图片供应商请求使用 mock 验证，没有调用真实付费图片供应商。供应商必须允许浏览器 CORS；HTTPS 页面不能请求被浏览器禁止的 HTTP 供应商。此限制不自动回退成手机代理。
- Google 服务账号私钥不下发浏览器；该模式需改用 API Key 供应商才能直接生成。
- 停止浏览器请求不保证供应商已取消服务端任务。浏览器关闭或本机挂起可能终止未完成的生成；已写入 IndexedDB 的结果可恢复。
- 本地证据位于 `docs/local/web-upgrade-*.log`，页面截图为 `web-images-mobile.png`、`web-ask-context.png`。
