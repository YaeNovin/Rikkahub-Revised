# 2026-09-12 源码更新 / Source update

This page records the grouped source changes prepared after release
`2.4.8-revised.7`. The same release tag has since been refreshed with rebuilt
APK/AAB assets; this page describes the source included in that refresh.

本页记录 `2.4.8-revised.7` 之后按组准备的源码变更；该 Release 已重新上传基于
最新源码构建的 APK/AAB 资产，本页描述的就是这次资产刷新所包含的源码。

## AI、Provider 与工具 / AI, providers and tools

- 新增 DeepSeek V4.1-Flash 规范名称 `deepseek-flash` 及旧别名识别，支持 1M 上下文、
  384K 最大输出、视觉输入、JSON 输出、思考强度和工具调用。
- 完善 OpenAI Chat Completions、Responses、Anthropic 及兼容端点的模型参数路由。
- 增强 `ask_user` 的富选项、滑块/评分、日期时间、确认倒计时、条件字段和草稿契约。
- 增加视频生成 Provider、后台任务状态、任务重试和生成保活支持。

## 应用、记忆与工作区 / Application, memory and workspace

- 增加后台异步记忆提取、事实/情景生命周期、对话隔离、向量索引和 Room 迁移。
- 扩展 SAF/本地文件访问、命令执行、路径校验和工作区工具审批。
- 增加上下文窗口统计、滚动摘要、请求诊断、统计详情和日志导出。
- 灵感启动卡片支持全局/助手配置、模式、变量、固定和空白对话默认关闭。

## 渲染与外观 / Rendering and appearance

- 内置离线 Mermaid、Graphviz、ECharts、Leaflet、铁路图、ABC/简谱、KaTeX、SVG 和
  Markdown 扩展资源及许可证。
- 修复 SVG、GeoJSON、Diff、LaTeX、Mermaid、HTML/WebView 预览、全屏拖动和返回位置。
- 增加 HCT/HEX 配色、背景可读性、液态玻璃、渐变和页面性能控制。
- 请求日志响应正文按 JSON、HTML/XML、SSE 和纯文本格式化显示。

## 验证与边界 / Verification and limits

- AI、应用、公共模块和 Material 配色的 JVM 测试与 QA Kotlin 编译已通过；完整命令见
  `scripts/README.md`。
- 浏览器渲染脚本使用本地 fixture 和打包资源，不能替代 Android 真机 GPU、触摸、
  生命周期及真实付费 Provider 验证。
- 生成的 APK、构建缓存、IDE 文件、日志、签名材料和本地配置不在上传范围。
