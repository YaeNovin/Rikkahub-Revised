# 云母式底层与卡片：第一阶段预览

日期：2026-09-28。实现为设置页局部预览，尚未推广到实际聊天页或全局页面。

## 可用性结论

云母式材质应当随时可用，不以启用背景图片为条件。它是有色调的不透明底层，卡片通过明暗层次与轻量边界区分；背景图片提供可选的配色来源，并不是渲染依赖。

| 条件 | 配色方式 | 预期观感 | 是否可用 |
| --- | --- | --- | --- |
| 无背景 | 当前主题色生成低彩度底色 | 更简洁、统一；卡片层次完整 | 是 |
| 有图片背景 | 复用现有图片采样与主色分组 | 与图片呼应、个性化更明显；不显示图片细节 | 是 |
| 有渐变背景 | 复用渐变配色计算静态样本 | 与渐变色调一致，预览没有持续动画 | 是 |
| 图片读取失败或尚未完成 | 暂用主题配色 | 仍有完整材质；失败时提供重试 | 是 |
| 不支持实时模糊 | 与其他设备相同 | 本阶段仅使用普通 Compose 绘制 | 是 |

“有背景更好”不是通用结论：彩色背景通常能带来更明显的个性化，但灰阶背景与低染色强度下差异会较小；无背景适合偏好主题统一、低干扰的阅读界面。浅色和深色都应保留两种来源，不根据图片的存在隐藏材质入口。

## 预览入口与边界

设置 → 高级外观 → 云母式外观 · 小范围预览 → 打开云母预览。

- 色调来源：无背景、示例色调、当前背景。示例是明确标记的蓝紫色样本，不冒充实际图片。
- 明暗：跟随当前应用、浅色、深色。改变预览不改变应用主题或状态栏。
- 染色强度：只影响预览材质的彩度，不调整真实背景的不透明度。
- 展示：一个静态底层、普通卡片和略高一级的卡片。预览内容为固定示例，不会发起模型请求。
- 所有预览控制仅保留局部 UI 状态，不写入设置存储，不改变现有磨砂、液态玻璃或聊天富内容设置。亚克力浮层留待下一阶段。

当前背景来源优先使用已启用且不透明度大于零的全局背景，其次使用既有聊天背景解析结果（当前助手图片／渐变）。全局页面即使使用实色表面，已启用的图片仍可供此处取色；这不会修改全局背景是否应用到聊天的开关。没有可用来源时仅禁用“当前背景”选项，主题预览仍可使用。

## 实现与性能

- `MicaPalette` 使用现有 HCT 工具限制彩度并生成固定明暗层次；没有新增依赖。
- `MicaBaseSurface` 绘制一次不透明渐变底层；`MicaCard` 使用原生 Surface，以色阶、细边界和轻阴影区分层级。
- 图片在展开预览后采样，成功后在当前预览生命周期内复用；切换明暗、来源或拖动强度不会重新下载／解码。换图使用独立状态，取消的旧请求不能覆盖新图。
- 不使用玻璃采样、离屏模糊、AGSL 或持续动画。不设置 Android 12／13 的功能门槛。具体帧耗时与功耗需要另行测量，不能由架构直接推断实测收益。
- 前景对比度沿用现有仅调文字的校正方式；底层与卡片是用户主动打开的新材质预览，不是恢复此前已移除的正文自动补底。

## 验证

JVM 检查覆盖深浅主题、空背景、灰阶及高饱和配色、强度边界、卡片层次、渐变中间色的文字对比度，以及背景来源解析。

设备用例只操作固定预览内容：对比深浅色与有／无示例色调四种组合，验证没有背景时仍可切换预览。截图用于评估材质观感，示例背景样本不等于已验证所有用户图片。

本轮结果：

- 应用编译、独立 Debug 包、Android 测试包构建通过。21 项定向 JVM 测试通过，无失败、错误或跳过；`git diff --check` 通过。
- vivo V2301A（Android API 36）通过独立包 `me.rerere.rikkahub.revised.renderperf` 展示了四种组合。已查看真实截图，确认底层与两级卡片均有内容，深浅色正文清晰、无截断；背景取色与主题取色呈现不同色调。
- `MicaPreviewDeviceTest` 的两个自动交互／截图用例在设备测试窗口启动阶段未完成，不能记为通过。已终止未完成的测试。
- 另提供 Debug 专用 `MicaPreviewActivity`，直接调用产品使用的同一套云母组件；仅显示固定样例，不读取聊天或更改设置，不进入 QA／Release。重复启动时使用 `am start -S -W` 及布尔参数 `dark`、`background`，确保各次取值重新进入 `onCreate`。
- 设备为独立测试包配置的“等待调试器”曾阻塞启动；取图期间临时解除，完成后已恢复原包名及等待开关。
- 四图对照产物：mica-comparison.png（本地生成，不随源码上传）。原始截图及对应 UI 树也在同目录。产物位于构建目录，不随源码发布。

实际对照支持“随时可用”的入口策略：示例背景取色从偏紫转为偏蓝，层次结构保持一致；无背景不是降级为缺失材质。观感偏好仍需后续 QA 收集，实际用户图片、提取失败重试、滑块及来源切换的完整设备交互测试尚未完成。未进行帧时间或功耗测量。本轮没有覆盖现有 QA 应用。
