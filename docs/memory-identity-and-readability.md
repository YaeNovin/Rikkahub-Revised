# 背景可读性、批量清理与记忆标识

本轮按截图修复记忆全屏预览的底图和文字颜色，再接入记忆 ID 基础设施。未改动用户现有记忆内容。

## 背景与文字

记忆全屏预览使用现有独立弹层背景，遵守高级外观的弹层样式、透明度和模糊设置；不透明模式则使用基础主题的底色与文字颜色。保留原始主题色方案，避免把为图片选择的黑色文字带入深色实体表面。

助手图片、全局图片及渐变背景采用共同的字色计算。2026-09-11 按测试反馈恢复原有背景叠色，移除自动黑白遮罩及自动提高表面不透明度的处理；图片、渐变、输入框、顶栏和卡片的底色与透明度由原有设置决定。字色采样会考虑既有叠色，独立弹层按自身底色计算，继续修复深色全屏预览继承黑字的问题。计算在背景或配置变化时进行，不逐帧截屏分析。

## 批量清理

入口位于聊天“最近记忆”以及助手记忆页的“清理”。界面显示全应用记忆和对话索引数量，并明确确认范围。清理包括所有助手与全局范围的事实/情景记忆，以及已存储的对话片段与向量；不清除聊天原文、知识库、附件和设置。

清理通过数据库事务执行；提取和索引写入使用代际检查，阻止清理前的在途结果重新写回。片段删除继续保存不含正文的内容版本排除标记。以后新产生的内容可以按设置形成新记忆。

## ID 基础

数据库 42→43 采用保留数据的显式迁移，旧整数主键保持不变。

| 字段/表 | 用途 |
| --- | --- |
| `uid` | 稳定 UUID，唯一索引；旧记录迁移时补齐，新记录生成时创建 |
| `revision` | 内容或生命周期变化时递增，编辑提交和后台更迭检查旧版本 |
| `scope_type`、`scope_id` | 区分对话、助手、全局和未归属记忆，与历史来源分开 |
| `content_hash` | 持久化正文 SHA-256，识别内容版本，不代替记录身份 |
| `superseded_by_uid` | 保留旧整数关联，同时补充稳定替代关系 |
| `memory_source` | 记录提取时参考的对话与消息；不宣称每一条都是事实的精确证据 |
| `embedding_key` | 模型、端点、路由、参数与分片版本指纹，拦截过期向量 |
| `memory_run` | 提取/向量任务 ID、操作、状态、时间、输入哈希和请求关联 |
| `memory_deletion` | 删除的 UUID、归属、版本与时间，不保留被删除正文；拒绝按已删除身份重新插入 |

记忆全屏预览可查看 UUID、版本、归属、配置指纹及提取任务，并跳转来源消息。编辑冲突会提示刷新，避免静默覆盖更新内容。向量配置不匹配时检索回退到文本匹配，重建后才使用新向量。

预览中的“重建向量索引”会调用已配置的向量模型，适用于旧向量或配置变化后的修复；完成后刷新向量及指纹信息。未配置可用模型时给出提示。

任务 ID 接入提取请求和向量请求诊断；日志只记录运行标识与状态，任务表不保存提示词或向量正文。多设备同步、历史快照回滚、回收站恢复仍属于后续功能，本轮提供它们所需的稳定标识与校验基础。

2026-09-11：QA Kotlin 编译通过；本地回归 65 项通过（应用 54 项、Embedding 协议 11 项），补丁空白检查通过。

独立 Android 回归包完成 6 项测试：42→43 迁移、UUID/版本/来源/删除标记、批量清理与在途写回保护，以及 3 项记忆提取和向量流程回归。只操作独立临时或内存数据库，原 QA 应用及其数据未清除。

深色预览像素测试未完成。首次及重试均停在测试 Activity 的同步启动等待；已改为有截止时间的启动方式，但更新测试驱动包的 ADB 安装长期未返回，随后取消等待。本地对比度测试通过，实际背景图片、全屏预览和字体的真机视觉效果仍需后续 QA 实测，不能以数据库测试代替此项。
