# 聊天加载、上下文统计与会话记忆隔离

## 加载体验

冷启动采用延迟出现的消息骨架与流光，内容首次就绪时短暂淡入。已展示的聊天列表继续保留；返回页面时仅用顶部细进度指示更新，不再显示居中的“正在加载对话”圆圈和文字。骨架不参与消息列表测量，也不修改滚动锚点；流光复用现有生命周期和系统动画开关。

## 上下文统计

- 真实聊天请求在消息转换、系统注入和媒体整理之后保存轻量统计快照，包含工具定义；不会把统计元数据发给供应商。
- 显示“当前上下文估算”和“最近请求输入（供应商统计）”，避免把历史调用用量当作当前上下文大小。
- 有有效快照时按服务端输入量校准，并增加本轮回复中下次实际可能发送的内容；不会把计费中的隐藏思考 Token 全部累加。历史思考文本是否估算为输入跟随协议和供应商配置。
- 编辑历史、切换模型/相关配置或更新摘要后，过期快照不再参与校准。旧对话没有完整快照时使用本地估算，同时保留历史服务端输入量作为单独参考。
- 多媒体及各类别仍是估算，后端可能采用不同的媒体分辨率、缓存和协议封装；分类和总数保持一致，不把估算伪装成逐项精确计数。
- 使用完整整数显示 Token；容量缺失或非法时不计算百分比。只在“更多”菜单打开时刷新统计，流式期间限频，避免持续解析文档和遍历长对话。

## 记忆隔离与预览

情景记忆必须属于当前对话，普通注入、RAG 检索、后台提取的去重与生命周期更新、聊天建议和最近记忆显示共用该规则。事实记忆继续按原有助手/全局设置共享。来源未知的旧情景记忆仍保留在管理页，但不自动注入任意对话。

分支继续继承分支点之前的聊天历史，后续情景记忆和对话索引独立生成，不实时共享源对话的后续记忆。继承的历史可以在分支内形成独立索引。

“最近记忆”中的记忆和对话片段提供全屏预览，可展开 ID、内容哈希、来源、向量模型、维度及向量数值。使用独立 Dialog 展示，不改变聊天导航或滚动位置。

## 删除与哈希

删除对话片段会移除该行及其向量，保留聊天原文。数据库只保存该片段版本的 ID 和内容哈希作为排除标记，后台重建和临时文本检索都会遵守该标记；已开始的向量请求也不能把已删除行重新写回来。修改原始内容产生新版本后，可以重新建立索引。

数据库从 41 升至 42，仅新增带对话外键的排除标记表，删除对话时标记随之清理。原有记忆记录不被迁移删除。

记录身份与内容版本是两件事：记忆已有主键，对话片段已有包含对话及来源消息的稳定 ID；SHA-256 用于检测内容变化、阻止旧向量回写及排除已删除版本。相同文字可以属于不同对话，不能用内容哈希代替记录 ID。对话索引已有持久化内容哈希，记忆全屏预览也提供内容哈希；记忆向量写回还会校验生成向量时的原文。
