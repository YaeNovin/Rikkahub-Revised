# Web 独立设置页第一阶段

日期：2026-10-06。

后续可编辑配置已落地，最新功能与测试状态见 [配置落地与验证](webui-settings-configuration-2026-10-06.md)。下文保留第一阶段记录，不代表当前配置能力。

## 已实现

聊天侧栏新增“设置”入口。桌面使用左侧分类导航，窄屏使用可换行的分类导航。支持直接访问、刷新、浏览器前进后退；从聊天进入时，返回按钮保留原会话地址。未知分类显示恢复入口。

| 板块 | 地址 | 本轮能力 |
| --- | --- | --- |
| 偏好设置 | `/settings/preferences`，`/settings` 默认页 | 浏览器主题、配色、语言、自定义 CSS，复用原有持久化 |
| 模型与服务 | `/settings/models` | 提供商、模型、搜索服务数量、MCP 状态只读展示 |
| 会话 | `/settings/conversations` | 已生效的手机共享输入/显示选项只读展示，说明会话管理入口 |
| 提示词与工作区 | `/settings/prompts-workspace` | 模式、世界书、快捷消息数量及工作区管理说明 |
| 连接与访问 | `/settings/connection` | 当前浏览器 origin、HTTP/HTTPS、重新加载连接入口 |
| 安全性 | `/settings/security` | Web 密码保护状态，撤销当前登录；失败时保留会话并提示重试 |

助手配置独立于全局设置分类。聊天页右上角“更多 → 助手设置”打开弹窗，复用模型、推理等级、搜索及 MCP 控件。助手头像入口仍用于选择助手。弹窗中的搜索/MCP 按钮增加文字，移动端模型名称可见；适配有限高度滚动和键盘关闭。

作用范围在界面中明确标注：浏览器偏好本地保存；已有助手设置操作通过原接口立即写回手机；部分搜索/模型工具选项为全局共享。共享只读数据继续订阅现有 settings SSE。

## 实现边界

- 这是设置页与入口落地，未新增后端管理 API，也未扩大安全 DTO 白名单。
- 温度、Top P、最大输出、上下文压缩、完整系统提示词和助手资料仍需在手机端编辑。
- 提供商密钥/地址、资源正文、工作区授权与模式、访问密码/端口等管理尚未开放网页编辑。页面明确显示只读或手机操作说明。
- 字号、自动滚动、代码自动折叠等此前“下发但未消费”的字段未加入可操作开关，留待显示行为同步阶段。
- 本地偏好沿用原 localStorage，不改变手机主题；本轮新增界面以中文显示。
- 连接页展示的是浏览器实际访问地址及协议，不宣称它就是反向代理后的手机监听地址，也不将已缓存设置当成连接健康证明。
