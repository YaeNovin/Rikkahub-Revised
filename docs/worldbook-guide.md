# 世界书使用与更新说明

在设置 → 扩展管理 → 提示词与世界书中管理世界书。点击书卡的“详情、模拟与批量操作”，可以查看助手默认引用、运行场景模拟、导出、复制和移动分类条目。

## 模式与预算

扫描范围与常驻相互独立。显式深度 0 表示不扫描任何消息，不会自动激活；NOT 条件或可匹配空串的正则也不会绕过“不扫描”。常驻条目不依赖扫描，只在已选中的世界书内作为候选，仍受预算、互斥和事件规则约束。

扫描模式可选择自定义（0–1000）、继承本书默认值、仅当前用户输入、不扫描。仅当前输入只读取最新用户消息的文本，不匹配更早历史或后续助手/工具消息。Tavern 的 null/缺省扫描深度导入为继承，显式 0 原样保留；来源没有提供默认深度时本书默认 4，可自行调整。

已由旧版本导入并被转换成 1 的条目无法可靠反推原始值，请重新导入源文件或手动修改。不要批量将所有深度 1 改成 0。

兼容性依据：[SillyTavern 官方 world-info.js](https://github.com/SillyTavern/SillyTavern/blob/release/public/scripts/world-info.js)，`WorldInfoBuffer.get` 对零深度返回空串，缺省使用默认深度；常驻在关键词匹配之前独立处理。

- 普通模式使用普通关键词；娱乐模式额外使用组合表达式、概率、持续与冷却、互斥组及单书预算。
- 两种模式均支持扫描来源选择和跨世界书总 Token 预算。
- 跨书总预算按照世界书列表顺序分配，书内按优先级选择。0 表示不限。预算采用本地文本 Token 估算，不等于供应商最终计费 Token 数。
- 启用表达式后会替代普通关键词条件；可视化条件辅助会生成表达式，应用前可检查文本。
- 引号内的 AND、OR、NOT 是普通关键词。引号和反斜杠可使用转义。

## 事件生命周期

- 一轮以用户消息计数，持续轮数包含首次激活的一轮。冷却从持续结束后开始。
- 概率采用对话种子、条目和轮次，重试同一轮可复现，不同对话独立。
- 只有成功完成生成才提交新的激活和冷却状态。失败或取消仍可查看诊断，但不提交本次状态。
- 修改规则、编辑最初触发的用户消息或回到触发之前的分支，会使不适用的旧激活状态失效。
- 同书同互斥组最多采用一个条目，优先保留持续激活中的条目。没有持续条目时：权重全为 0 按优先级；存在正权重则按权重随机，0 权重不参与。
- 允许对话级提示词配置时，在聊天扩展菜单取消世界书，只关闭当前对话，不改变助手默认设置。再次选中可恢复。

## 编辑、导入和恢复

原生导出（`version: 1`、`type: lorebook`、`data`）与 Tavern 文件分别解析。原生文件中的 `top_of_chat`、`bottom_of_chat` 等位置原样保留，不套用 Tavern 数字位置映射。旧版未保存扫描模式字段时沿用自定义数值深度，0 和常驻设置均保留；不会根据名称或另一份世界书自动补写互斥组等缺失设置。

原生导入重新生成书和条目 ID，并保留停用条目；未识别的版本或损坏字段会报告具体错误，不降级为其他格式。新版扫描模式、默认深度、预算和互斥配置均支持导出再导入。导入生成的是新副本，合并或替换已有书仍需在预览中确认。

- 编辑条目时，正文、触发条件和高级设置分组展示。数字可清空重填，保存前检查范围和表达式错误。
- 编辑书时可按名称、内容或条件搜索，按分类筛选，批量启停及修改分类。删除条目后可撤销。
- 每本书保留最近 10 个已保存的旧版本，恢复后需要保存。历史仅本地保留，导出默认只包含当前版本。
- 独立世界书与角色卡内嵌世界书共用 Tavern 转换。导入报告会列出跳过、调整和已识别的不支持字段；递归扫描等尚不支持的能力不会被伪装成已生效。
- 独立世界书导入提供另存、合并、替换。合并按名称匹配条目；已有同名条目采用导入内容并保留原 ID。请检查预览后确认。
- 独立世界书 JSON 最大 16 MiB，单次最多 10000 个条目。

## 场景模拟与诊断

模拟器复用聊天评估器，无须模型调用，不写入真实对话。可以输入此前助手回复和本轮用户消息，逐轮推进，验证扫描来源、概率、持续、冷却、互斥及预算。可同时模拟其他世界书，观察总预算分配。

诊断显示匹配词项、采用状态、位置、估算 Token、持续与冷却剩余轮数，以及实际注入正文。模拟预览止于世界书注入阶段，不代表后续供应商协议转换、其他提示词模板及上下文压缩的最终请求。
