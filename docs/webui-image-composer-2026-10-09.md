# Web 图片生成优化

- 图片页采用视口高度布局：图库独立滚动，底部提示词输入框与聊天框一致，模型、参数和参考图通过弹出菜单选择。
- 侧栏语言按钮旁新增图片按钮，设置改为同组图标，移除主题按钮旁的品牌文字。
- 请求、参考图上传、供应商图片下载和解码均由浏览器完成；Android 只提供连接配置及最终落库接口。供应商必须支持浏览器 CORS，失败时不会自动切换为手机代理。
- 浏览器待保存记录包含提示词、所选生成参数、供应商返回文字和图片。刷新或断连后仍可重试保存，不重复生成。
- Room 44 → 45 自动迁移增加两个可空字段，保留现有图库；图片列表返回参数和结果文字。历史原生图片的新增字段为空。
- 管理图片模型后返回图片页。

验证日志：`docs/local/web-image-layout-*.log`。供应商使用模拟响应，未调用收费生成服务。

验证结果：前端类型检查、15 项单元测试、5 项 Edge 浏览器测试、17 项 Android Web 单元测试和 2 项真机测试通过。参考图二进制直传、参数及返回文字回传、失败恢复、幂等重试、手机尺寸底部布局均有覆盖。真机仅覆盖安装独立 `me.rerere.rikkahub.revised.websettingsqa` 测试包，未操作原 QA 或正式应用数据。

再次验证：`docs/local/image-layout-build.log`、`image-layout-browser.log`、`image-layout-android.log`、`image-layout-device.log` 记录本轮构建和回归结果，全部通过。已检查生成的 44→45 迁移，仅通过 ALTER TABLE 增加两个可空 TEXT 字段，不删除或重建图库。真机验证包括提示词、参数、供应商返回文字的数据库读回与图库接口读回，以及重复上传返回同一记录。供应商响应仍为测试模拟，不代表已验证真实供应商的跨域策略。
