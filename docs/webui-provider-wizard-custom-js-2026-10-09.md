# Web 供应商向导与 Custom JS 搜索

## 交付内容

- 添加和编辑供应商采用三步弹窗：基础内容、模型配置、高级设置。供应商名称选填，留空使用服务域名；Base URL 与新供应商 API Key 标记必填。已有密钥不回显，留空保留。
- 模型配置支持手动输入模型 ID、图标按钮拉取模型、自动打开多选菜单，以及聊天／嵌入／图片类型切换。弹窗高度随内容变化，手机宽度下保留边距和滚动范围。
- 高级页保留模型上下文、模态、能力、自定义请求头／请求体、内置工具及供应商重写配置。高级字段按模型分配独立标识。
- 新增认证保护的 `POST /api/settings/manage/providers/discover`，直接使用未保存草稿拉取模型；已有供应商凭据按 ID 合并，仅用于此次请求，不写入配置。取消弹窗不保存；完成弹窗后由页面“保存配置”提交，并保留原有并发修改保护。
- Custom JS 搜索提供 URL、请求参数名、结果字段映射，以及 POST JSON、Bearer 鉴权、数量参数、无效链接过滤、链接去重、限制条数、网页抓取复选项。启用可视化模式前确认替换脚本，之后修改自动生成脚本；无效配置阻止保存。
- 生成脚本采用 Android QuickJS 的同步 fetch 协议，与软件共享的 searchScript/scrapeScript 字段一致。保留手动编辑；已有手写脚本不自动反向转换，密钥及原脚本不回显。抓取选项返回网页原始正文，不做通用正文提取。

## 本轮验证

- TypeScript 检查通过，18 项前端单元测试通过（含脚本执行、编码、鉴权、映射、过滤、去重及错误响应）。
- 5 项 Edge 浏览器测试通过，包括必填校验、取消草稿、未保存配置拉取模型、勾选和改类型、高级请求体、手机弹窗布局、自动生成脚本及无效配置拦截。
- Android 服务端编译和 18 项 Web 单元测试通过，包括草稿密钥合并、地址校验、原配置不变、配置隔离及认证回归。
- 日志：`docs/local/provider-wizard-build.log`、`provider-wizard-browser-final.log`、`provider-wizard-android.log`；截图：`docs/local/provider-wizard-mobile.png`。

本轮未安装 APK 或调用真实供应商／搜索服务；模型发现采用模拟接口，生成脚本在测试运行时按同步 fetch 协议验证，未在 Android QuickJS 真机上执行。
